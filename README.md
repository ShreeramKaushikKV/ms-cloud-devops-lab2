## 5. The four traps

For each trap, write what you saw and why it happened, in two or three lines of your own words.

**Trap 1 — the local image.**
The Pods failed with an 'ErrImagePull' status because the Kubernetes worker nodes cannot access my laptop's local Docker storage. To fix it, I had to upload (push) the image to a public registry like Docker Hub so the nodes could download it.

**Trap 2 — the selector typo.**
I changed one letter in Service section (second half of the code) from 'app: hello-app' to 'app: helo-app, so the web page broke because the Service's selector (helo-app) no longer matched the Pods' actual label (hello-app). Because of this mismatch, the Service's EndpointSlice became empty, meaning it had no Pods to send the web traffic to.

**Trap 3 — the wrong targetPort.**
I changed the target port number in Service section (second half of the code) from 'targetPort: 80' to 'targetPort: 8080' but the Service successfully found the Pods (the EndpointSlice was populated), but the web page still broke because the Service sent traffic to port 8080 inside the container. NGINX was only listening on port 80, so it rejected the connection.

**Trap 4 — the EXTERNAL-IP address.**
The IP address shown under EXTERNAL-IP didn't work in my browser because it is an internal private IP isolated inside Docker Desktop's network. I had to use localhost:8080 instead because Docker Desktop automatically maps that port to my laptop.
